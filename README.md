# ClassVoice

Single-college, multi-department teacher and student feedback system. Java 21 + Spring Boot + Thymeleaf + PostgreSQL.
Full spec: `REQUIREMENTS.md`. Plan: `MASTER_PLAN.md`. Status: `CURRENT_STATUS.md`. Setup: `SETUP.md`.

Quick start (local, no database install): `./scripts/run-dev.sh` then open http://localhost:8080/setup.
